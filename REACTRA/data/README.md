# RECTRA Synthetic Demonstration Data

## Notice & Disclaimers
- All imagery, colorimetric measurements, and metadata in this directory are **entirely synthetic**.
- This dataset is automatically generated by `scripts/generate_demo_data.py` for algorithmic testing and prototype demonstration only.
- **Must never contain real illicit drug test images or real forensic evidence.**
- Not validated for real-world clinical, forensic, or legal use.

## Generation
To regenerate the demo dataset deterministically:
```bash
python scripts/generate_demo_data.py --seed 42
```
